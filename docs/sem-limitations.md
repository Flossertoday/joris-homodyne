# SEM 限制报告：26-08-04 数据集 g2 测量的统计极限

本文归档 26-08-04 HBT 批次 g⁽²⁾(0) 测量的统计误差（SEM，均值标准误）受哪些因素主导、
各自量级多少、哪些有补救空间。数字来自 Fig. 2(c) 复刻任务（执行文档
[26-08-04-fig2c.md](26-08-04-fig2c.md)；门槛报告
`drafts/26-08-06_fig2c/power_gate_report.json`）；结论同样适用于后续二维 g⁽²⁾ 与
cross-mesa 关联的统计预算。

## 1. 结论摘要

19992 帧下：逐 bin SEM(g⁽²⁾) 中位 5.9–26(1–4 px 分箱)，窗口汇总 g⁽²⁾(0) 精度
L ±0.41 / R ±0.18，锁相振荡 95% 灵敏度（反相合并）中位 0.78。**第一杠杆是帧数×信号率，
第二杠杆是底噪（~2× SEM 惩罚，分析端无解），周期长短对本数据集无害。**

## 2. SEM 的因式分解

零延迟 g⁽²⁾ 的逐 bin SEM 在符合计数极限下为

SEM ≈ √(m₁m₂/F) / (s₁s₂) = 1/√(F·s₁s₂) × 1/√(纯度₁·纯度₂)

其中 m = 每帧每臂总检测事件率（信号+噪声），s = 信号率（m − β），纯度 = s/m，
F = 帧数。各因子按本数据集实测排序：

| 因子 | 本数据集数值 | 对 SEM 的影响 | 补救空间 |
|---|---|---|---|
| 帧数 F | 19992 | ∝ 1/√F | 加数据（3×10⁵ 帧可覆盖论文下限 0.2) |
| 信号率 s | 0.50–1.21 events/帧/臂（0–820 ps) | 平方杠杆:s×2 → SEM÷2 | 通量/收集/探测效率、检测阈值损失 |
| 底噪占比 | 噪声占带内事件 45–55% | SEM ×2.0(R 对）–2.3(L 对） ≈ 帧数 ÷4–5 | **分析端无解（§3)，采集端才行** |
| bin 宽×周期 | sinc(Δt/T):0.757 @9.84 ps,0.995 @37.2 ps(4 px bin) | 灵敏度罚 1.32×(9.84 ps) / ≈1(37.2 ps) | 我们周期长(§4)，实际无罚 |
| t0 对齐残差 | CFD50:偏差 −0.10 px,std 0.33 px | ≪ 4 px bin，可忽略 | 已足够 |
| 信号关联时间 vs bin 宽 | 若真实 g⁽²⁾ 峰只有几 ps 宽，4 px bin 开始稀释 | 时间分辨率↔统计的老权衡 | 与上一条联动 |

帧数缩放表（符合计数极限，SEM ∝ 1/√F，同条件同速率假设）:

| 帧数 | 振荡 95% 灵敏度（中位 / 9.84 ps) | pooled g⁽²⁾(0) SEM (L/R) |
|---|---|---|
| 20k（现有） | 0.78 / 1.01 | 0.41 / 0.18 |
| 72k | 0.41 / 0.53 | 0.22 / 0.10 |
| 92k（两批合并） | 0.36 / 0.47 | 0.19 / 0.09 |
| ~300k | 0.20 / 0.26（覆盖论文下限） | 0.10 / 0.05 |

## 3. 底噪问题

**事实**：实测背景扣除后，事件检测（8-连通、25 counts、min 2 px）在四条发光带之外
同样触发。带外 45 个子窗（450 px 宽）给出残余噪声事件面密度 ρ(τ) ≈ 1.19×10⁻⁵
events/帧/列 px/1-px bin，沿 τ 平坦（χ²/ndf = 1.16)、沿 x 平坦，Poisson 行为。
折合每条带 0.70–1.10 个噪声事件/帧，而带内实测总数 1.20–2.30/帧——**带内事件的
45–55% 是残余探测器噪声团**（可能混入真实弥散散射光子；对 g2 二者等效，两臂间
不相关）。

**影响**：噪声不制造假信号（β 修正用带外密度精确消掉它对 g⁽²⁾ 均值的贡献），但方差
由总计数驱动——SEM 相对同信号率的无噪声实验恶化 ~2–2.3 倍，**等效于损失 4–5 倍帧数**。
这是本数据集仅次于"帧数×信号率"的第二大统计限制。

**分析端补救均已实测无效**:

- 提高检测阈值（25→70 counts，500 帧探针）：噪声只降 ~11%，信号同步降 ~6%——
  噪声团与真光子的幅度分布相近，逐事件不可分，优值不变；
- 缩窄分析窗（用子窗迹线扫描最优核心窗）：信号在带内分布均匀，核心窗保留 90–100%
  信号而纯度几乎不变，**收益仅 1–4%**。

**能改善的只有采集端**：探测器本底/暗计数、门控与 EM 增益设置、减少杂散光。
若新批次数据本底更低，其统计价值优于同等幅度的帧数增加（噪声减半 ≈ 帧数 ×2)。

## 4. 周期与 bin 宽

论文 Fig. 2(c) 的 9.84 ps 是其共振激发条件下的 Josephson 周期；本数据集（非共振
reservoir-fed + Stark kick）的实测振荡周期为 37.2 ps（次峰 41.8 ps,k 空间同步扫描
干涉条纹直接测得，见 [26-08-04-fig2a.md](26-08-04-fig2a.md))。bin 平均对周期 T 的
衰减因子为 sinc(Δt/T):4 px bin(3.94 ps）对 9.84 ps 衰减 0.757（灵敏度罚 1.32×),
对 37.2 ps 仅 0.995（无实质惩罚）。**本数据集周期更长，bin 宽选择对灵敏度基本无影响**;
fig2c 的振荡检验扫描覆盖 3–200 ps 并在 9.84/37.2/41.8 ps 做了精确周期针对性拟合。
