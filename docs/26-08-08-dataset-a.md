# 26-08-04 HBT 数据集A:排除一切"不可能是数据"的峰后的复刻判定

目标(用户验收条件,2026-08-07/08):为判定"Fig. 2(a)/2(c) 复刻零结果是算法问题还是
数据问题",构建数据集A——每帧经恰当的横向 ROI 与峰值检测,排除一切不可能是凝聚体
信号的点;后续全部分析只引用数据集A,不再触碰原始帧。若零结果在数据集A上仍成立,
且注入验证证明该链对论文强度信号灵敏,则零结果归于数据。

## 调查定案(2026-08-08,先行于策展器设计)

对现有策展事件表(275218 事件、20000 帧)与 2000 帧抽样形态学再提取
(`tmp/dataset_a_invest/`,主仓 tmp 下同)的定量结论:

1. **横向 ROI 已近最优**:对每带做窗宽 S/√(S+N) 扫描,现行定案窗
   (B1 380–450、B2 570–680、B3 810–880、B4 1010–1110)与最优点相差 <0.6%
   (`part1b_summary.json`)。带外事件(占全部检出的 40%)为纯噪声样本,排除。
2. **形态学不能分离信号与噪声**:信号与噪声事件是同一物理对象(MCP 云斑);
   带内/带外事件的幅度、尺寸、峰值、长宽分布逐点重合(part1/part2 图)。
   任何逐事件形态裁剪要改善灵敏度需以 ≥3:1 的速率舍噪声优于舍信号
   (N≈S 时的边际条件),实测最好的判别量(事件尺寸)只有 1.7:1——故**不做形态裁剪**。
   size>300 px 的"巨团"经 patch 目检是重叠的两个真实光子(0.2%),保留;
   size 2–6 的小团是真实弱光子与噪声斑点的混合(3.4%),无诚实分法,保留。
3. **可排除的缺陷类**:1-px 热列(全时间均匀、幅度谱与邻列相同 → 探测器缺陷):
   带内仅列 676(B2 内,z=14.5,0.031 vs 邻列 0.017 events/frame);带外
   567/744/970 与检测范围边缘列 350-351/1147-1148 由 ROI 天然排除。
   (2026-08-10 更正:边缘列 350-351/1147-1148 的尖峰实为**检测列界截断堆积**——
   左界外移到 330 重算后尖峰随之出现在 330/331,而 350/351 回落到地板水平;
   真热列是带外 567/744/970 与带内 676。排除决定不受影响(截断事件位置本就
   不可信),仅机制定性更正。见 docs/26-08-08-band-window-methods.md
   "左界 330 重跑"节。)
   触帧边事件(bbox 触及行 0/1015 或检测列界,1.4%)位置不可信,排除。
4. **τ 不做逐事件裁剪**:带内超量(信号)从 τ≈−63 ps 起贯穿全程
   (kick 前有真实预激发射),超出 0–820 ps 分析窗的事件由下游窗函数处理。
5. **噪声地板是空间固定图样**(分块相关 0.97),逐带局部地板与全局均值差
   ±20–30%;旧管线用全局均值估 β,对本批各带有 ±30–50% 的相对偏差。
   数据集A的噪声模型用**逐带局部线性拟合**(带边外 30 px 防护带排除实测
   ~25–30 px 的信号尾巴,35 px 拟合窗,B1 因左邻检测边缘采用右侧单边),
   变体极差作系统误差。
6. **无帧级剔除**:逐帧带外计数 Fano 1.07(近 Poisson),20000 帧仅 1 帧离群。

## 验证

1. **检测回归**:`detect_events_features` 与生产 `detect_events` 逐位一致
   (单元测试 + 全量验证:检出事件总数逐位相同)。
2. **包含关系**:verify_dataset_a.py(上)。
3. **帧级注入端到端**(`dataset_a_frame_injection.py`,真实帧 + 394 个真实
   事件 patch 库,注入位置锚定各帧 CFD50 t0):
   - **z 模式**(Fig. 2(a) 式,2856 帧,注入 z 振幅 0.5、9.84 ps 反相):
     注入 10867 个 blob,**保留率 98.8%**(10738;损失为重叠合并/缺陷列/触边),
     t0 零扰动(逐帧差恰为 0 px);恢复振幅 0.165 ± 0.0076(22σ)vs 期望测量值
     0.182(= A·s_inj/(S+N+s_inj),注入事件与真实信号共同进入分母)——
     一致于 10% 内,链对人口振荡透明且可定量恢复。
   - **bunching 模式**(Fig. 2(c) 式,全 19992 帧,A_pk=6、9.84 ps 反相、
     增长包络;注入为同 τ 跨臂对):注入 252 blob(126 对),**保留率 99.6%**,
     t0 零扰动。注入的 R 臂 pooled g⁽²⁾ 从 1.065 升到 1.622(+0.56,期望
     +0.65);9.84 ps 处恢复振荡振幅 R 0.788 ± 0.247(3.2σ、符号正确)、
     L |A| 0.727 ± 0.518(L 臂 σ 约 2 倍于 R,相位不定)——期望测量值
     0.66(= 0.249 × 2.63;0.249 = 4 px 分箱下"同 τ 对"到 g⁽²⁾−1 的几何
     稀释因子 4·(208/833)²,2.63 = 包络平均后的注入振幅),一致。
     **该注入比 G7 立方注入弱 4 倍**(后者按 bin 级归一化,直接给出
     g⁽²⁾−1 = A),两级互相印证:估计器无偏(G7),帧级链透明(本项)。
4. **立方级注入**(`fig2c_synthetic_injection.py --out-dir` 数据集A g2 目录):
   强注入(A_pk 6→8)集合振幅偏差 L −2.2%、R −7.9%(判据 <10%),周期恢复
   2% 内 L 15/16、R 16/16,全部 rep 显著;论文强度(A_pk 1.5→2)集合无偏
   (L −1.5%、R +7.6%),单 rep 检出率 L 31%、R 81%(旧管线 19%/50%——
   局部 β 带来的纯度改善直接转化为检出率)。
5. **MC 无偏性**:G3 已验证(解析/MC 0.86–1.07);β 变体夹逼见上。
