# 数据集A的噪声假设：定义、证据与实现（26-08-04 HBT）

**BLUF**：数据集A把"残余噪声"从逐事件属性改写为三条可检验的统计假设——
(1) 噪声事件与信号事件是**同一物理对象**（MCP 云斑，形态分布逐点重合），逐事件
不可分，只能统计处理；(2) 噪声在分析窗（0–820 ps）内沿 τ **平坦**
（χ²/ndf = 1.15，834 个 1-px bin），故 β 用每行常数密度 `floor/N_ROWS`；
(3) 噪声沿列是**空间固定图样**（分块相关 0.97）而非全局常数——全局均值相对
逐带局部地板偏高 +17–24%，故 β 必须用**逐带局部线性拟合**（30 px 防护带排除
实测 ~25–30 px 信号尾巴，35 px 拟合窗，变体极差 ±3–6% 作系统误差）。
β 选择的残余不确定度由"局部地板 vs 旧式全局均值"两个变体全程夹逼：4 px pooled
g⁽²⁾(0) L 对 0.531±0.258（局部）vs 0.307±0.388（全局），变体差小于统计误差，
且全局变体几乎逐位复现旧管线结果（0.310/1.114）。帧级注入（98.8–99.6% 保留、
t0 零扰动、恢复振幅与期望一致）与立方级注入（偏差 <10%）证明该噪声处理对论文
强度信号透明且无偏。**结论：Fig. 2(a)/2(c) 的零结果不能归因于噪声处理；残余
噪声以 40–51% 的分数稀释灵敏度，但已被 β 修正与稀释修正定量补偿。**

## 1. 前因：噪声假设为什么成了关键问题

旧管线（2026-08-06 定案，见 `docs/26-08-04-fig2a.md` / `docs/26-08-04-fig2c.md`）
对 Fig. 2(a) 强度反相振荡与 Fig. 2(c) 时分辨 g⁽²⁾(0) 的复刻均给出零结果。
当时的 G3 功率门槛已指出：**约半数检出事件是残余探测器噪声团**（实测背景
`StreakCamBackG` 逐帧扣除后仍越过 25 counts 阈值的离散云斑）。这留下一个开口：
零结果究竟是数据本身没有信号，还是检测/噪声处理把信号淹了？

用户验收条件（2026-08-07/08）：构建数据集A——"每个事件都可能是凝聚体信号"
的策展事件集，下游分析只引用它，不再触碰原始帧；若零结果在数据集A上仍成立，
且注入验证证明该链对论文强度信号灵敏，则零结果归于数据。

2026-08-08 的先行调查（`tmp/dataset_a_invest/`，定案六条见
`docs/26-08-08-dataset-a.md` "调查定案"）中第 2、5、6 条直接构成噪声假设的
经验基础，下文逐条展开。

## 2. 噪声的物理本质

每帧的实测背景（平滑辉光）已在检测前扣除；剩下的"噪声事件"是越过检测阈值
（≥2 px、积分 >25 counts）的**离散 MCP 云斑**——与信号光子事件是探测器对同类
单电子事件的同一响应，只是不来自凝聚体的四条发射带。两个直接后果：

- **逐事件不可分**：带内/带外事件的幅度、尺寸、峰值、长宽比分布逐点重合；
  最好的判别量（事件尺寸）舍噪声相对舍信号的速率只有 1.7:1，低于 N≈S 时
  改善灵敏度所需的 ~3:1 边际条件——任何形态裁剪都净损灵敏度，故不做。
- **只能统计处理**：噪声以"地板密度"的形式进入下游（g⁽²⁾ 的 β 修正、
  Fig. 2(a) 的稀释修正），不以逐事件标签进入。

## 4. 实现：内嵌噪声模型

数据集A**故意不含带外事件**，β 无法像旧管线那样在下游重新从带外估计——
因此噪声模型必须与事件集在**同一遍**策展中产出并内嵌进文件
（`detected-peaks/26-08-04_hbt_time_reference_dataset_a.h5` 的 `noise_model/` 组）：

| 数据集 | 内容 |
|---|---|
| `floor_per_band` (4,) | 逐带残余噪声地板密度 [events/frame/col]，行积分；主量 |
| `floor_variants` (4,3) | (guard, fit) 三变体的地板，极差 = 拟合系统误差 |
| `rho_tau_global` (1144,) | 旧管线式全局带外密度（τ 分辨，1 px），变体夹逼用 |
| `tau_grid` (1144,) | ρ 的 τ 栅（−64…1079 px） |
| `out_of_band_col_rate` (800,) | 带外逐列事件率（固定图样的原始记录） |
| `noise_tau_hist` / `band_tau_hist` / `detected_col_hist` | 平坦度检验与 QC 直方图 |
| attrs：`flatness_chi2_ndf_window_0_820ps` = 1.147、`out_of_band_width_cols` = 446、`floor_report_json`、裁剪计数 | 检验与 provenance |

**地板拟合算法**（`fit_band_floors`）：对每带取两翼窗
`[edge−guard−fit, edge−guard)` 与 `(edge+guard, edge+guard+fit]` 的带外列，
剔除缺陷列与检测边缘列（默认 350/351/567/676/744/970/1147/1148——1-px 热列，
时间均匀、幅度谱与邻列相同，判为探测器缺陷）后拟合列向直线，在带窗下积分。
某翼可用列 <10 时退化为另翼单边常数：B1 恒为右翼单边（左邻检测边缘），
B4 的 (30,35)/(35,40) 变体为左翼单边（右翼被 1147/1148 边缘列压缩到 7/2 列）。

实测地板（events/frame/col，行积分；均值 ± 变体半极差）：

| 带 | 带窗 | 地板 | 半极差 | 单边 |
|---|---|---|---|---|
| B1 | 380–450 | 0.009623 | ±4.3% | 右 |
| B2 | 570–680 | 0.009850 | ±2.8% | — |
| B3 | 810–880 | 0.010140 | ±3.6% | — |
| B4 | 1010–1110 | 0.009451 | ±6.4% | 左（2/3 变体） |

**β 的两种构造**（`dataset_a_g2.py`）：

- 主量 `beta_from_noise_model`：β_c = `floor_c / N_ROWS`（1016 行，τ 平坦
  ⇒ 每行常数密度）× 带内列数（hi−lo+1，含端点成员约定）× bin 宽；
- 变体 `beta_global_variant`：`rho_tau_global` 重分 bin × (hi−lo)——
  旧管线公式在策展数据上的复刻，用于夹逼 β 选择的系统误差。
  两者 1 列的宽度约定差（hi−lo+1 vs hi−lo，~1.4%）远小于变体间物理差，
  不影响夹逼结论。

## 5. 验证证据汇总

1. **τ 平坦**：窗内 χ²/ndf = 1.147（假设 N2 直接通过）。
2. **变体夹逼**：4 px pooled g⁽²⁾(0)（jackknife SEM）——局部 β：L 0.531±0.258、
   R 1.065±0.135；全局 β 变体：L 0.307±0.388、R 1.094±0.194。变体差
   （L 0.22、R 0.03）小于统计误差。
3. **链一致性交叉验证**：全局变体几乎逐位复现旧管线对原始事件表的结果
   （0.310±0.380 / 1.114±0.188）——计数立方与估计器链在策展数据上无漂移，
   两批数字之差纯由 β 假设造成。
4. **帧级注入**（`dataset_a_frame_injection.py`，真实帧 + 394 个真实事件 patch）：
   注入 blob 保留率 98.8%（z 模式）/ 99.6%（bunching 模式），逐帧 t0 扰动
   恰为 0 px；恢复振幅与含稀释的期望值一致（10% 内）——噪声处理（含 β）对
   论文强度信号透明。
5. **立方级注入**（G7 脚本原样复用）：强注入振幅偏差 L −2.2% / R −7.9%
   （判据 <10%）；论文强度集合无偏；单 rep 检出率 L 31% / R 81%，优于旧管线
   （19%/50%）——局部 β 的纯度改善直接转化为检出率。
6. **MC 无偏性**：估计器层面 G3 已验（解析/MC 0.86–1.07）。

## 6. 后果与继承约定

- **灵敏度稀释**：逐带残余噪声分数 B1 43.9% / B2 40.3% / B3 50.6% / B4 40.2%
  （旧全局估计 53/48/59/50%）。Fig. 2(a) 的振幅上限须做稀释修正
  （S/(S+N) ≈ 0.58/0.57 两臂），修正后真实人口调制 95% 上限 ≈ 0.0226——
  论文全对比度反相（z ≈ ±0.66）超出约 30 倍，零结果决定性。
- **Fig. 2(c) 上限收紧**：局部 β 使锁相振荡 95% 上限中位从 0.81 降至 0.58
  （~30%），论文幅度区间上半覆盖改善；结论不变（零结果）。
- **下游纪律**：数据集A之后所有分析（`dataset_a_traces.py`、`dataset_a_g2.py`、
  `dataset_a_fig2a_analysis.py`、`dataset_a_frame_injection.py`）只读数据集A
  文件（事件 + 内嵌噪声模型），不再访问原始帧；β 一律取自 `noise_model/`，
  不重新估计。
- **补充批次（72000 帧）同链**：热列明显增多（11 条带内缺陷列，z 最高 39；
  地板拟合另排除带外热列与边缘列），残余分数 B1 52% / B2 45% / B3 58% /
  B4 47%；全部假设与夹逼机制原样继承，结果与主批次一致（零结果）。
