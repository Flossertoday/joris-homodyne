## 脉冲时间定位方法 (2026-08-06 判定)

### 论文怎么定位时间: 未写算法

论文主文与 SI 均未给出参考脉冲的定位算法。SI (Supplementary Note 1) 只有一句: 把一小束激发激光打在条纹相机狭缝上, "use it as a time reference", 用于在长时程采集中校正条纹相机的时间抖动; 参考点在帧上如何逐帧定行位置, 完全没有写。

### 参考脉冲的实际形态 (26-08-04 HBT 条件实测)

在 `hbt_condensate_josephson_regime` 帧上取参考点 ROI (行 110–210 × 列 170–215), 扣实测背景后按列求和得到行廓线:

- **非高斯、强不对称**: 前沿陡峭 (10%→90% 约 5 px ≈ 5 ps), 顶部平坦、常呈双峰 (~2 px), 后沿拖一条带肩部的重尾——峰后 +11 px 处仍有 ~3% 峰高 (同 FWHM 的高斯在该处应 ~10⁻⁵)。FWHM ≈ 5.5 px ≈ 5.4 ps, 逐帧宽度可见变化 (抽样帧 4.8–8.6 px)。
- **形状逐帧呼吸**: 同一帧分别用 half-max 质心与前沿 50% 穿越定时, 逐帧差 std ≈ 1.2–1.5 px ≈ 1.3 ps; 而前沿穿越点的光子噪声仅 ~0.02 px (脉冲亮、前沿斜率大), 故该差异几乎全部是真实的脉冲/IRF 形状涨落, 不是统计噪声。肩部位置逐帧可见移动。
- **双态形状一致**: 时间抖动的双态 (态间距 21.6 px ≈ 21.3 ps) 平均廓线几乎重合; 两种定时给出的态间距差仅 0.09 ps → 双态之间是纯平移, 此前担心的「两态间扫速可能不同」在本数据集上不成立。

结论: 参考脉冲不是对称高斯斑, `peak-localization.md` 里稀疏亮斑的质心方案不适用——那里质心胜出是因为斑近似对称; 这里廓线明显不对称且形状呼吸, 任何对尾部加权的估计量 (质心、全廓线互相关) 都会把形状呼吸误当成时间移动。

### 选定方法: 前沿恒比定时 (leading-edge constant-fraction discrimination, CFD)

逐帧, 在参考 ROI 行廓线上 (扣背景、按列求和, 前处理与现行管线相同):

1. 找廓线峰值 `A` 与峰行; 峰未高出噪声下限 (沿用现行 5σ 规则) 的帧直接丢弃;
2. 在峰行**之前**的前沿上, 取最后一个低于 `f·A` 的行与首个不低于 `f·A` 的行, 线性插值出 `f·A` 的穿越行, 即该帧 t0 (亚行精度);
3. 比例取 `f = 0.5`: 半高点正落在前沿最陡区, 信噪比最高; 实测降到 f = 0.2 结果基本不变, 说明选择不敏感。

等价表述: 对前沿拟合累积高斯 `I(t) ∝ ½[1+erf((t−t0)/(σ√2))]`, t0 即半高点——这是超快泵浦-探测/时间分辨发光定时间零点的通行约定 (瞬时激发下记录的上升沿 = 仪器响应函数的积分, 半高点 = IRF 中心)。CFD 是其免拟合版本。

经典依据:

- **CFD 是快定时电子学的标准方法**, 为消除幅度游动 (amplitude walk) 而生: Gedcke & McDonald, "Design of the constant fraction of pulse height trigger for optimum time resolution", Nucl. Instrum. Methods 58, 253–260 (1968), [DOI 10.1016/0029-554X(68)90473-4](https://doi.org/10.1016/0029-554X(68)90473-4)。核物理、LIDAR、TCSPC 的脉冲到达时间一律取前沿恒比穿越, 而不是峰位或质心。
- **物理上也对**: 样品与参考点是同一个激光脉冲 (两臂延迟实测 0.32 ps), 脉冲到达时间由前沿标记; 后沿与肩部是条纹相机 IRF 自身的衰减动态, 不与到达时间同步呼吸。实测的 ~1.3 ps 形状呼吸, 只有前沿定时能排除。

### 与现行 half-max 质心法的定量差异 (2000 帧抽样实测)

| 量 | 数值 |
|---|---|
| 质心 − CFD50 恒定偏移 | +2.72 px ≈ +2.7 ps (质心被重尾拖晚) |
| 质心 − CFD50 逐帧差 std | 1.2–1.5 px ≈ 1.3 ps (形状呼吸跟踪差) |
| 幅度游动 (峰高变 100%) | 质心 −0.54 ps; CFD50 −0.36 ps; CFD20 −0.24 ps |

注意: t0 的绝对定义改变 → Fig. 2(a) 时间原点整体提前 ~2.7 ps。另外需复查旧的合成注入恢复验证用的参考点形状——若合成参考点是对称形状, 该验证并未考验对真实非高斯脉冲的跟踪, 需用真实参考脉冲形状重做。

### 对「上一轮没找到振荡」的诚实评估

- 1.3 ps 的随机跟踪误差对相干幅度的衰减: 37 ps 周期 (k 空间实测) 仅 ~2%, 9.8 ps 周期 ~30% —— 定时方法本身不足以解释实空间零结果, 但它是方法论上正确的选择, 且消除了一个随形状呼吸的系统误差源。
- 仍开放的时间标定缺口: 行→ps 换算 (0.984 ps/px) 与 row 0 约定来自采集元数据, 未经数据内标定; 参考脉冲定时只解决逐帧对齐, 不解决绝对时间轴。
